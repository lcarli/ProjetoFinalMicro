# Projeto Final Micro

Este repositório reúne o material base do projeto final de **modernização do Spring PetClinic** com foco em **micro serviços** e no uso de recursos do **Microsoft Azure**.

## Objetivo

O projeto propõe a análise da aplicação **Spring PetClinic**, originalmente monolítica, para identificar oportunidades de evolução arquitetural, escalabilidade, segurança, automação e governança em nuvem.

## O que você encontrará neste repositório

- **Guia do aluno** com a contextualização do projeto;
- **Casos de uso** da aplicação atual;
- **Diagramas** para apoiar a análise da arquitetura;
- **Perguntas de reflexão** sobre a transformação da solução em micro serviços.

## Projeto de referência

A aplicação analisada neste trabalho é o **Spring PetClinic**:

- Repositório oficial: https://github.com/spring-projects/spring-petclinic

## Temas abordados

O material do projeto direciona a análise para temas como:

- divisão de responsabilidades em micro serviços;
- escalabilidade e resiliência;
- armazenamento de dados;
- automação e CI/CD;
- comunicação entre serviços;
- segurança;
- governança e organização de recursos no Azure;
- identidade e controle de acesso com Azure AD e RBAC.
